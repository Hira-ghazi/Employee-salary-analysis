# Dataset files

- `Employee_Salaries_raw.csv`: the original 10,291 employee records from the supplied CSV body.
- `cleaned_employee_salary.csv`: notebook-matched cleaned records used for all dashboard analysis.

Run `python clean_data.py` from the project folder to regenerate the cleaned CSV and `models/inference_preprocessing.json`. The dashboard also accepts a cleaned CSV upload. No data is synthesized.
